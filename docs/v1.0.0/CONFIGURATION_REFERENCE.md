## Overview

AutoVideo uses a hierarchical configuration system:

1. **config.json** - Main configuration file
2. **Environment Variables** - Override config file settings
3. **CLI Flags** - Override all other settings
4. **Defaults** - Fallback values in code

### Priority (Highest to Lowest)

```
CLI Flags > Environment Variables > config.json > Defaults
```

## Configuration File Structure

### Default Location

```
~/.autovideo/config.json       # User config (global)
./config.json                   # Project config (local)
./autovideo_config.json         # Legacy config name
```

### Generate Default Config

```bash
python -m video_renderer --init-config
```

## Core Settings

### output_dir
- **Type**: `string`
- **Default**: `"output"`
- **Description**: Directory for rendered video files
- **Example**: `"output", "renders", "/path/to/output"`

### temp_dir
- **Type**: `string`
- **Default**: `"tmp"`
- **Description**: Directory for temporary/intermediate files
- **Example**: `"tmp", "/tmp/autovideo"`

### archive_dir
- **Type**: `string`
- **Default**: `"archive"`
- **Description**: Directory for archived source files
- **Example**: `"archive", "/backup/videos"`

### log_dir
- **Type**: `string`
- **Default**: `"logs"`
- **Description**: Directory for log files
- **Example**: `"logs", "/var/log/autovideo"`

### log_level
- **Type**: `string`
- **Default**: `"INFO"`
- **Options**: `"DEBUG"`, `"INFO"`, `"WARNING"`, `"ERROR"`, `"CRITICAL"`
- **Description**: Logging verbosity level

## Encoder Settings

### default_codec
- **Type**: `string`
- **Default**: `"libx264"`
- **Options**: Software: `libx264`, `libx265`, `libaom-av1`
  Hardware: `h264_nvenc`, `hevc_nvenc`, `h264_qsv`, `hevc_qsv`, `h264_vaapi`
- **Description**: Default video codec for encoding

### preset
- **Type**: `string`
- **Default**: `"medium"`
- **Options**: `ultrafast`, `superfast`, `veryfast`, `faster`, `fast`, `medium`, `slow`, `slower`, `veryslow`
- **Description**: Encoding speed/efficiency tradeoff

### crf
- **Type**: `integer`
- **Default**: `23`
- **Range**: `0-51` (lower = better quality, larger file)
- **Description**: Constant Rate Factor for quality-based encoding

### hardware_acceleration
- **Type**: `boolean`
- **Default**: `true`
- **Description**: Enable hardware encoder detection and usage

### preferred_encoders
- **Type**: `array[string]`
- **Default**: `["nvenc", "qsv", "vaapi"]`
- **Description**: Hardware encoder priority order

### fallback_to_software
- **Type**: `boolean`
- **Default**: `true`
- **Description**: Fall back to software encoding if hardware unavailable

## Video Settings

### normalize
- **Type**: `boolean`
- **Default**: `true`
- **Description**: Normalize video encoding parameters

### match_resolution
- **Type**: `boolean`
- **Default**: `true`
- **Description**: Match intro and loop resolutions when possible

### target_resolution
- **Type**: `string | null`
- **Default**: `null`
- **Format**: `"WIDTHxHEIGHT"` or `"1080p"`, `"720p"`, `"480p"`
- **Description**: Force target resolution (null = preserve source)

### target_fps
- **Type**: `integer | null`
- **Default**: `null`
- **Description**: Force target framerate (null = preserve source)

### pixel_format
- **Type**: `string`
- **Default**: `"yuv420p"`
- **Options**: `yuv420p`, `yuv422p`, `yuv444p`, `nv12`, `p010`
- **Description**: Output pixel format

---

## Audio Settings

### codec
- **Type**: `string`
- **Default**: `"aac"`
- **Options**: `aac`, `libmp3lame`, `libopus`, `flac`, `pcm_s16le`
- **Description**: Audio codec for output

### bitrate
- **Type**: `string`
- **Default**: `"192k"`
- **Format**: `"BITRATEk"` or `"BITRATEK"`
- **Description**: Audio bitrate

### sample_rate
- **Type**: `integer`
- **Default**: `48000`
- **Options**: `44100`, `48000`, `96000`
- **Description**: Audio sample rate in Hz

### channels
- **Type**: `integer`
- **Default**: `2`
- **Options**: `1` (mono), `2` (stereo), `6` (5.1)
- **Description**: Number of audio channels

### normalize
- **Type**: `boolean`
- **Default**: `false`
- **Description**: Normalize audio levels

### background_gain
- **Type**: `float`
- **Default**: `-10.0`
- **Range**: `-60.0 to 0.0`
- **Description**: Background audio gain in dB

---

## Duration Settings

### mode
- **Type**: `string`
- **Default**: `"fixed"`
- **Options**: `fixed`, `custom`, `random`, `preset`
- **Description**: Duration calculation mode

### target_hours
- **Type**: `integer`
- **Default**: `8`
- **Description**: Target duration in hours (for fixed/preset modes)

### custom_seconds
- **Type**: `integer | null`
- **Default**: `null`
- **Description**: Custom duration in seconds

### random_min_hours
- **Type**: `integer`
- **Default**: `8`
- **Description**: Minimum duration for random mode

### random_max_hours
- **Type**: `integer`
- **Default**: `10`
- **Description**: Maximum duration for random mode

## Cloud Integration

### Google Drive

#### enabled
- **Type**: `boolean`
- **Default**: `false`
- **Description**: Enable Google Drive uploads

#### folder_id
- **Type**: `string | null`
- **Default**: `null`
- **Description**: Target Drive folder ID (null = root)

#### upload_after_render
- **Type**: `boolean`
- **Default**: `false`
- **Description**: Upload immediately after render completes

### YouTube

#### enabled
- **Type**: `boolean`
- **Default**: `false`
- **Description**: Enable YouTube uploads

#### default_privacy
- **Type**: `string`
- **Default**: `"unlisted"`
- **Options**: `public`, `unlisted`, `private`
- **Description**: Default video privacy status

#### default_title
- **Type**: `string`
- **Default**: `"{name} - {duration}"`
- **Variables**: `{name}`, `{duration}`, `{date}`, `{codec}`
- **Description**: Video title template

#### default_description
- **Type**: `string`
- **Default**: `"Generated by AutoVideo"`
- **Description**: Default video description

#### tags
- **Type**: `array[string]`
- **Default**: `["autovideo", "loop"]`
- **Description**: Default video tags

## Ramtest Mode Settings

### enabled
- **Type**: `boolean`
- **Default**: `false`
- **Description**: Enable RAM-optimized mode

### use_ramdisk
- **Type**: `boolean`
- **Default**: `true`
- **Description**: Use RAM disk for temp files (Linux only)

### ramdisk_path
- **Type**: `string`
- **Default**: `"/dev/shm/autovideo"`
- **Description**: RAM disk mount point

### high_vram
- **Type**: `boolean`
- **Default**: `false`
- **Description**: Enable high-VRAM GPU optimizations

### chunk_long_videos
- **Type**: `boolean`
- **Default**: `false`
- **Description**: Chunk long videos for reduced memory usage

## Environment Variables

### Core

```bash
AUTOVIDEO_CONFIG_DIR="/path/to/config"     # Config directory
AUTOVIDEO_OUTPUT_DIR="/path/to/output"     # Output directory
AUTOVIDEO_TEMP_DIR="/path/to/tmp"          # Temp directory
AUTOVIDEO_LOG_LEVEL="DEBUG"                # Log level
```

### Encoder

```bash
AUTOVIDEO_CODEC="libx264"                  # Default codec
AUTOVIDEO_PRESET="medium"                  # Encoding preset
AUTOVIDEO_CRF=23                           # Quality setting
AUTOVIDEO_HW_ACCEL=1                       # Hardware acceleration (0/1)
```

### Cloud

```bash
GOOGLE_DRIVE_FOLDER_ID="abc123"            # Drive folder ID
GOOGLE_DRIVE_ENABLED=1                     # Enable Drive upload
YOUTUBE_ENABLED=0                          # Disable YouTube upload
YOUTUBE_PRIVACY="unlisted"                 # Video privacy
```

### Ramtest

```bash
AUTOVIDEO_RAMTEST=1                        # Enable ramtest mode
AUTOVIDEO_RAMDISK="/dev/shm/autovideo"     # RAM disk path
AUTOVIDEO_HIGH_VRAM=1                      # High VRAM mode
```

### Security

```bash
AUTOVIDEO_VALIDATE_PATHS=1                 # Path validation
AUTOVIDEO_AUDIT_LOG=1                      # Audit logging
```

## Configuration Validation

### Validate Config File

```bash
python -m video_renderer --validate-config
```

### Schema Validation

The configuration follows JSON Schema. Get the schema:

```bash
python -m video_renderer --config-schema > config-schema.json
```

### Common Validation Errors

| Error | Cause | Solution |
|-------|-------|----------|
| `Invalid codec` | Unknown codec name | Check available encoders with `--list-codecs` |
| `CRF out of range` | CRF not 0-51 | Use value between 0 and 51 |
| `Invalid preset` | Unknown preset | Use valid preset for codec |
| `Path not found` | Directory doesn't exist | Create directory or use absolute path |
| `Permission denied` | No write access | Check directory permissions |
